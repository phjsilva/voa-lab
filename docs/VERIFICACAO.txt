VERIFICAÇÃO DO PROJETO SEM CSVs INICIAIS

47 testes aprovados.

- A página inicial funciona sem arquivos CSV cadastrados.
- A busca só aparece após a importação de dois CSVs válidos.
- Consultar antes da importação devolve uma mensagem de orientação.
- A primeira importação ativa os dados sem reiniciar o servidor.
- Os dados importados persistem após reiniciar a aplicação.
- Uma primeira importação inválida mantém o estado sem dados.
- CSVs soltos em data/ não são carregados automaticamente.
- Os modelos para download contêm somente os cabeçalhos.
- Não existe mais a rota de restauração de uma base de exemplo.
- Os testes matemáticos usam dados temporários próprios, sem base pré-carregada no site.

- As duas tabelas exibem as linhas dos CSVs importados, sem filtrar pela busca.
- Escrita, ordem, repetições e cidades sem companhia foram verificadas.

- A página /apresentacao funciona sem dados importados.
- Os trechos de código são obtidos diretamente dos arquivos Python.
- O menu conecta a busca à página de códigos.

- Guia por abas com funções inteiras, linhas reais e destaques.
- Navegação anterior/próximo e atalhos de teclado.
- Os exemplos usam somente CSVs importados pelo usuário.

SIMPLIFICAÇÃO DIDÁTICA
- Filtrar e contar elementos em funções próprias e curtas.
- Escolha das operações com if, sem dicionário de funções.
- Resolução explícita de interseções antes de uniões e diferenças.
- Parênteses e validação de CSV em funções auxiliares.
